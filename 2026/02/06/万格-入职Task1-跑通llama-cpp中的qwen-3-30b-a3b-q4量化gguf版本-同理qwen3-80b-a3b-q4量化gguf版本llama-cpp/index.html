Task 2 - 环境工程阶段：

  • 挑战：宿主机 nvcc 11.5 无法满足 Qwen3 专用内核的编译需求。
  • 方案：决定通过 Docker 容器化方案隔离 CUDA 12.8 环境。
  • 优化：针对 30GB 磁盘空间不足的瓶颈，主动清理了 /mnt/ExtDisk 冗余数据，并扩容 100GB 专用存储，同时将 Docker data-root 重定向至外置硬盘，确保了大规模深度学习环境的构建稳定性。

Task 1 - 方案 A (llama.cpp) 实验结论：

  • 模型：Qwen3-30B-A3B-Q4_K_M (17.28 GiB)
  • 硬件：RTX 3060 (6G) + 12G RAM
  • 结论：成功跑通。得益于 Qwen3 的 MoE 架构（Active 3B），生成速度高达 23.4 t/s。
  • 技术洞察：虽然物理内存不足，但由于 MoE 每次仅调用少量专家，磁盘 IO 交换并未成为 30B 模型的致命瓶颈。
